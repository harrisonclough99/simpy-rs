# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `simpy-rs` (for example, memory safety issues in unsafe blocks, denial-of-service panics across the FFI boundary, or supply-chain concerns):

1. **Do not** open a public GitHub issue.
2. Report it privately using GitHub's **Security Advisories** ("Report a vulnerability" under the Security tab) or contact the maintainers directly.
3. Include a minimal reproduction script, your Python version, OS, and `simpy_rs.__version__`.

We aim to acknowledge reports within 48 hours and provide a fix or mitigation plan promptly.
